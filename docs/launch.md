# Open notebooks on their original platform

Pipeline A conditions base models on a test CoT column. Pipeline B compares fine-tuned answer checkpoints without a test CoT column. Each button follows the original platform. Kaggle links import the matching GitHub copy; original published Kaggle URLs were not present in the exports. Configure data, secrets, and GPU before running. Working notebooks can be updated; original evidence stays in the pinned Git snapshot.

The buttons do not run cells. See [reproduction](reproduction.md) and [the workflow trace](workflows.md).
