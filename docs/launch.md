# Open notebooks on their original platform

Each notebook keeps its original platform, determined from the committed Colab/Kaggle metadata. Colab buttons open the matching organized GitHub notebook in Colab. Kaggle buttons import the matching GitHub notebook into a Kaggle editor; the exports do not contain original published Kaggle notebook URLs, so these are labeled import links rather than published-run links. Code, execution counts, and all saved outputs are unchanged.

Launching does not run cells automatically. Attach the required data, configure secrets, and select the correct GPU before running. Saved outputs can be inspected on GitHub without executing cells.
